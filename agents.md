rules for the repo

1. Be as consise in all text output as you can, every extra word is a waste of time and space.
2. Reuse functions and methods everywhere possible, create an index with documentation on every function created.
3. DO NOT add extra tests for things that don't need testing, minimal testing and only when absolutely necessary.
4. Avoid unnecassarily complex code, if you want to write something complex in a one liner rather do it in two, the code should be readable and understandable by anyone.
