# Slay The Spire 2 - vim keybind mod

## the project

like the title of the plan says, i want to create a mod for StS2 that allows playing the game from the keyboard only, with vim keybinds. The mod should be as minimal as possible, and should not change any of the core mechanics of the game. The mod should be compatible with the latest version of the game, and should be easy to install and uninstall.

## plan of attack

- find the modding documentation for StS2 and read it thoroughly
- read up on the basic actions available in the game, if i remember correctly they can be split into 3 categories
  1. combat actions (attacking, defending, using skills, etc.)
  2. exploration and event interactions (moving around the map, interacting with events, etc.)
  3. deck management (adding/removing cards, viewing the deck, etc.)
- there are also some actions that can be taken in any state
  - opening the menu, opening the settings, etc.
  - looking at relics, viewing the journal, etc.
  - using or discarding potions, etc.
